# Mushaf muthaman (المصحف المثمن)

Pages en couleur (tajwid), un thumun par page : 485 images `001.jpg` … `485.jpg`.
001 Fatiha, 002 Baqara 1-4, 003 suite du hizb 1 thumun 1, puis un thumun par image ; dans le hizb 60, les thumuns 5, 7 et 8 occupent deux images (480, 483, 485).

Téléchargées par l'application Mushaf Warsh (édition « muthaman »).

`nouveautes.json` : nouveautés de la dernière version de l'appli, affichées dans le dialogue « إصدار جديد متاح » (`versionCode` = version proposée, `ar` = texte). À changer à chaque version publiée.
